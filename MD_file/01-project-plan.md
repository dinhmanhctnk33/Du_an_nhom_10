# 14. AI RISK MANAGEMENT

Đặc biệt xem xét:

### AI Hallucination

AI có thể tạo thông tin không chính xác.

Biện pháp:

> Human verification + source validation.

### Prompt Injection

Đối với AI trong sản phẩm:

> Giới hạn input và quyền truy cập dữ liệu.

### API Key Leakage

Không hard-code API key.

### Timeout / Rate Limit

Phải có error handling.

### Invalid AI Response

Phải kiểm tra output trước khi sử dụng.
